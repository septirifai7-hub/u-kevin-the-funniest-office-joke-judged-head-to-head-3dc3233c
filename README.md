# The Funniest Office Joke, Judged Head to Head

A standup meeting runs so long that even the office tools start quitting.

## The entry

`main.py` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## How it works

Run it with:

```sh
python3 main.py
```

`main.py` holds the entry text in `ENTRY`, returns it from `get_entry()`, and writes it from `write_entry()`. The output is a single line of plain UTF-8 text with no trailing newline.

## About this entry

The joke escalates from the ticketing system filing a complaint to the coffee machine resigning in the chat. The meeting is the villain; the tools are the victims.
